# 山河十四卷 · 宋韵水墨武侠单机

> 纯前端零依赖的宋韵青绿山水风武侠 RPG：26 大经典区域、141 间子房间探索、十四天书与八大门派 115 幕立绘剧场、玉简策略回合战斗、零体积 `Web Audio` 国风音效与藏经阁百层试炼。
>
> **▶ 在线试玩：<https://yegy.github.io/shanhe-14/>**

## 核心特色

- **宋韵青绿原创视觉**：绢白素底配黛青墨绿顶栏与泥金篆印，左竖排孤本卷首标题屏、左宽幅主舞台 + 右侧青黛挂轴舆图栏 + 悬浮玉简操作坞，全库内含 77 张国风水墨 WebP 原画（支持点击高清灯箱鉴赏）。
- **26 区 × 141 间子房间**：涵盖悦来镇、襄阳、江南、长安、八大门派及桃花岛、冰火岛、黑木崖、雁门关、华山之巅，含 12 时辰昼夜切换、暗格搜查、采集、客栈与夜间黑市。
- **38 部多幕立绘剧本（115 幕 · 33 场剧情实战）**：完整收录十四天书、八大门派三幕长卷、十二同道多节奏深度支线、散修奇遇与华山论剑三阵终局大戏。
- **玉简策略回合战斗**：敌方下回合意图提前预警，38 门武功支持点穴打断、破甲碎盾、太极借力反震、寒/毒/血连携引爆、同道默契追击与 12 位同道专属合击。
- **养成与终局重玩**：奇经八脉、八大门派 4 阶晋升与客卿无损转投、9 件原著神兵 + 4 部位锻造强化洗词条、五大生活技艺（炼丹/锻造/烹饪/古琴曲谱/珍珑残局）、少室藏经阁百层试炼塔与二周目宗师轮回传承。
- **国风音效与跨端存档**：纯前端 `Web Audio API` 实时合成刀剑/拳掌/点穴/古琴/棋石音效与五声环境雅乐；支持 3 栏位本地存档及 `SH14:` 跨端存档备份码。

## 本地运行与离线打包

无需安装任何依赖，使用 Node 即可本地预览、打包离线版或运行全量测试：

```bash
# 1. 本地预览（http://127.0.0.1:8123/）
node _serve.js

# 2. 打包成可断网双击游玩的单文件 HTML（输出至 dist/）
node _bundle.js

# 3. 运行数据校验与 18 组自动化测试
node _validate_data.js && node _test.js
```
